## Five words

Helm uses five words, and they always mean the same thing.

- **Capability**: one thing you can see or do, such as showing a document or running a notebook. It has a
  face you see and, for the agent, instructions on how to use it.
- **Workbench**: the capabilities for one kind of artifact, such as a story or a web page.
- **Workspace**: the place in a project for one job, holding the workbenches it needs.
- **Artifact**: the thing you're working on: a story, a web page, an interview, a table.
- **Project**: workspaces together, in one folder on your computer.

A whole project set up for a kind of work, shared in the Marketplace, is a **template**.
