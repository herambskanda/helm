# Keyboard shortcuts

[Guide](README.md) · previous: [Settings](settings.md)

**Mod** below is **⌘** (Command) on a Mac and **Ctrl** on Windows and Linux. The three pane shortcuts use the
**Control** key on every system, including a Mac.

| What | Shortcut |
|---|---|
| Show or hide the sidebar | Mod B |
| All projects | Mod O |
| New project | Mod N |
| Open the **Files** pane | Control Shift E |
| Open the **Terminal** pane | Control \` (the backtick key, left of 1) |
| Open the **Agent** pane | Control Shift A |
| Pin a note (turn note-pinning on or off) | N (when you aren't typing in a box) |
| Save a note you've written | Mod Enter |
| Send a message | Enter |
| New line in a message | Shift Enter |
| Choose a command from the **/** list | Up and Down, then Enter or Tab |
| Take back a message waiting in line | Up (in an empty message box) |
| Stop what the agent is doing | Esc (in an empty message box) |
| Save a file you're editing in the Files pane | Mod S |
| Rename the selected item in the sidebar | F2 |
| Close the open menu, sheet or pane; cancel a rename | Esc |

In the terminal, copy and paste are Mod C and Mod V on a Mac, and **Ctrl Shift C** and **Ctrl Shift V** on Windows and Linux (so Ctrl C still stops a command). **Mod K** clears the terminal on a Mac; **Ctrl Shift K** does on Windows and Linux.

Pressing a pane's button again closes it. Esc closes the pane too.
