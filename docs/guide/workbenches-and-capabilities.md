# Workbenches and capabilities

[Guide](README.md) · previous: [Workspaces](workspaces.md) · next: [Artifacts](artifacts.md)

## Capability

A **capability** is one thing you can see or do. It has a **face** for you and, for the agent, instructions on how to use it. Some capabilities show things (a document, an image, a web page, a PDF), some run things (a notebook, a terminal), and some are small tools (a calculator). A capability knows kinds of content. It never knows your project.

Capability names say what they do: **Document view**, **Table editor**, **Evidence board**.

## Workbench

A **workbench** is the capabilities for one kind of artifact, side by side. The **User story** workbench is a story card, a flow diagram, an evidence board and a text editor, all working on one story. A **Web page** workbench is a preview, a text editor and a preview server. The workbench also teaches the agent what a good story or web page is.

You can change a workbench's layout (side by side, stacked or in tabs) and swap or add its capabilities. That happens in the [Studio](studio.md).

## Every name is a door

Click almost any name in Helm, such as a capability, workbench or workspace, and a small card opens. It says what it is, its version, where it came from, and its file, with buttons: **Edit in Studio**, **See on the map**, **See its runs**, and Show in {Finder, File Explorer or your file manager}.

If you want to see the names and file types beside the friendly ones, turn on **Settings › Appearance › Show the parts**.

## Where they come from

Helm comes with capabilities (marked *built in*). It comes with **no workbenches** of its own. Get them in the [Marketplace](marketplace.md), such as **Everyday workbenches** (Document, Table, Image, PDF, Slides, Web page) or **Data and media workbenches** (Notebook, Dashboard, Recording, Video), or make your own in the [Studio](studio.md).
