# The agent doesn't answer

[Help](README.md)

You send a message and nothing comes back, or it stops partway. Try these in order.

1. **Wait a moment.** Long answers take a minute. The message box shows a ring while it works, and **Stop** is there if you need it.
2. **Are you signed in?** Open **Settings › Agents**. The agent should say **Signed in as …**. If it says **Not signed in**, click **Sign in**. See [Sign in or switch accounts](sign-in.md).
3. **Have you hit your limit?** Open **Agent pane › Usage** (the Agent button at the top right). It shows your plan's 5-hour and weekly limits and when each resets. If one is full, wait for the reset, or switch to the other agent: **Agent pane › Setup › Agent**.
4. **Is the internet working?** The agents need it. Open a web page to check.
5. **Try another model or effort.** **Agent pane › Setup**. A lower effort answers faster.
6. **Start fresh.** Open **New task** and ask again. If a long conversation is the problem, **Agent pane › Context › Compact now** shortens it.
7. **Quit and reopen Helm** (menu bar, notification area or tray icon › **Quit Helm**).
8. **Still nothing?** [Report a problem](report-a-problem.md) and say which agent and what you typed.

A permission card waiting for you also looks like silence: scroll to the bottom of the conversation, and answer **Allow once**, **Always allow** or **No**. With a routine, look in the [Control center](../guide/control-center.md) for **Waiting for you**.
